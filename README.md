# Mohamed Musthakeem M — Premium AI/ML Portfolio

React + TypeScript + Vite portfolio designed for VS Code, GitHub and Netlify.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Profile photo

Place the real supplied professional photograph at `public/profile-photo.webp`. No synthetic face is generated; if the photo is missing, the hero uses a restrained MM monogram fallback.

## GitHub

```bash
git init
git add .
git commit -m "Upgrade premium AI ML portfolio"
git branch -M main
git remote add origin https://github.com/Mohamedmusthakeem/musthakeem-portfolio.git
git push -u origin main
```

If the remote already exists:

```bash
git remote set-url origin https://github.com/Mohamedmusthakeem/musthakeem-portfolio.git
git push -u origin main
```

## Netlify

Import the GitHub repository. `netlify.toml` configures `npm run build` and `dist`. Netlify Forms is configured for the contact form.
